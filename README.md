# 🗡️ SS3D — 星穹：尖塔

**3D卡牌Roguelike | 米哈游二次元风格 × 杀戮尖塔核心玩法**

> 🎯 大二寒假实习作品集项目
> 🛠 Unity 6 + C# + AI辅助开发
> 📅 2025年7月启动

---

## 🎮 游戏概述

- **类型**: 3D 单人卡牌 Roguelike
- **核心玩法**: 回合制卡牌战斗 + 随机地图爬塔
- **视觉风格**: 米哈游式二次元渲染 (cel shading + 描边 + 华丽粒子)
- **参考**: Slay the Spire (玩法) × 崩坏：星穹铁道 (美术)

## 🏗 技术栈

| 层 | 技术 |
|----|------|
| 引擎 | Unity 6 LTS (URP) |
| 语言 | C# (.NET 8) |
| 渲染 | URP + Shader Graph + 自定义Cel Shading |
| AI工具 | Claude/GPT 辅助代码/Shader/关卡设计 |
| 版本控制 | Git + GitHub |

## 📁 项目结构

```
Assets/
├── Scripts/        # C# 代码
│   ├── Core/       # 核心系统 (GameManager, 战斗引擎)
│   ├── Cards/      # 卡牌系统
│   ├── Characters/ # 角色/敌人
│   ├── UI/         # UI面板
│   └── Utils/      # 工具类
├── Scenes/         # Unity场景文件
├── Prefabs/        # 预制体
├── Art/            # 美术资源
│   ├── Materials/
│   ├── Textures/
│   └── Models/
├── Audio/          # 音频
│   ├── BGM/
│   └── SFX/
└── Resources/      # 动态加载资源
```
